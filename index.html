Linux Commands

Essential commands for Linux system navigation

📂 ls

List directory contents. Shows files and folders in the current location.

ls -l
Use -l for detailed view, -a to show hidden files
Read More
🚶 cd

Change directory. Navigate between folders in the system.

cd Documents
Use cd .. to go up one level, cd ~ for home directory
Read More
📍 pwd

Print working directory. Shows your current location in the system.

pwd
Useful when you need to know your exact location
Read More
📁 mkdir

Make directory. Creates a new folder in the specified location.

mkdir new_folder
Use -p to create nested directories
Read More
🗑️ rmdir/rm

Remove files or directories from the system.

rm -r folder_name
Use -r for directories, -f to force deletion
Read More
📋 cp

Copy files and directories from one location to another.

cp file.txt backup/
Use -r to copy directories recursively
Read More
✂️ mv

Move or rename files and directories.

mv old.txt new.txt
Can be used for both moving and renaming
Read More
📑 cat

Display contents of a file in the terminal.

cat file.txt
Can also combine multiple files
Read More
✨ touch

Create empty files or update file timestamps.

touch newfile.txt
Creates new empty file if it doesn't exist
Read More
🔍 grep

Search for patterns in files or command output.

grep "pattern" file.txt
Use -i for case-insensitive search
