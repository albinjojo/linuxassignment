🚶 cd - Change directories

cd

The cd (change directory) command is used to navigate between directories in Linux. It is a fundamental tool for managing and accessing different parts of the filesystem.


Purpose and Functionality
  • Change the current working directory.
  • Navigate to relative or absolute paths in the filesystem.
  • Move quickly between directories using shortcuts like .. or ~.

Key Features of the cd Command
  • Move to a Directory: Allows navigation to a specific directory using its path.
  • Relative Path Navigation: Navigate using paths relative to the current directory.
  • Absolute Path Navigation: Use the full path to switch to a directory, starting from the root (/).

Shortcuts for Navigation:
  • .. moves to the parent directory.
  • ~ moves to the home directory.
  • - switches to the previous directory.
