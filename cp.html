📋 cp - Copy files and directories

cp

The cp command is one of the fundamental file management commands in Linux, used to copy files and directories. It is an essential tool for duplicating data and organizing file structures. The cp command ensures that the original file or directory remains intact while creating a duplicate copy at the desired location.


Purpose and Functionality

  • Duplicate files from one location to another.
  • entire directories, including their contents, recursively.
  • Preserve file attributes, such as permissions and timestamps, during the copy process.
  • options for safer and more controlled file copying.

Key Features of the cp Command

  • File Duplication: Copies individual files from one directory to another.
  • Recursive Directory Copy: Allows entire directories to be copied along with their subdirectories and contents using the -r option.
  • Preservation of Attributes: Retains file metadata (like timestamps, permissions, and ownership) using the -p or -a options.
  • Interactive Copying: Prompts the user before overwriting existing files with the -i option, reducing the risk of accidental data loss.
  • Selective Copying: Copies files only if they are newer or missing in the destination directory with the -u option.
