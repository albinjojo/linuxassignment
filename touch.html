✨ touch - Create empty files

touch

The touch command is used to create new empty files or update the timestamps of existing files.
Purpose and Functionality

  • Quickly create empty files.
  • Update the access and modification times of existing files.

Features of the touch Command
  • File Creation: Creates empty files.
  • Timestamp Modification: Updates timestamps without altering file content.
