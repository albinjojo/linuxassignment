✂️ mv - Move or rename

mv

The mv (move) command is used to move or rename files and directories.
Purpose and Functionality

  • Relocate files and directories to a different location.
  • Rename files or directories.

Key Features of the mv Command
  • File Relocation: Moves files from one directory to another.
  • Renaming: Renames a file or directory by specifying a new name in the destination.
  • Interactive Mode: Use -i to confirm before overwriting files.
